# 00. 프로젝트 개요

## 목적
실시간 카메라 스트림을 입력으로 받아 프레임/이벤트 단위 레코드를 생성하고,
VLA 학습에 사용할 정렬된 멀티모달 데이터셋을 자동으로 축적한다.

## 구현 범위
- baseline 파이프라인(모듈 인터페이스 + curation + export)
- YOLO 기반 spatial encoder 연동 경로
- GRU 기반 temporal encoder 학습/추론 분리 구조
- run -> processed dataset 변환 경로
- 실험/산출물 체계화(`experiments/`, `artifacts/`)

## 데이터셋 사용 원칙
차량 내부에서 외부를 촬영한 데이터셋은 차량 시스템 자체 완성보다
제안 구조의 실효성(연결성/정렬/정제/재현성) 검증을 1차 목표로 사용한다.
