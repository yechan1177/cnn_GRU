# 01. 시스템 아키텍처

## 상위 모듈
1. `CameraStream`: 프레임 입력 공급 (`mock`, `image_folder`)
2. `SpatialEncoder`: 프레임 -> 고정 길이 벡터 (`mock`, `yolo`)
3. `FeaturePacker`: temporal 입력 형태로 정규화
4. `TemporalEncoder`: 맥락 확률/경계 신호 추정 (`gru_mock`, `gru_torch`)
5. `EventScorer`: context/boundary/uncertainty/novelty 결합
6. `AutoCurationEngine`: ring buffer 기반 저장 정책 결정
7. `DatasetExporter`: frame/event/aligned JSONL 내보내기

## 데이터 흐름
1. 프레임 수집
2. spatial 벡터 추출
3. temporal 맥락 추정
4. 이벤트 점수화
5. clip/keyframe/discard 정책 적용
6. frame/event/aligned 데이터 저장

## 설계 이유
- 인터페이스 기반 모듈화로 실모델 교체 비용 최소화
- 배포 환경 메모리 제약 대응을 위해 ring buffer 중심 저장 정책 적용
- 실험 재현성을 위해 run/processed/experiment/artifact 경로를 분리
