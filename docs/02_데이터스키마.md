# 02. 데이터 스키마

## 공통 원칙
- `sensor_timestamp`와 `system_timestamp`를 분리 저장
- `frame-level`과 `event-level` 레코드를 분리 저장
- `raw_path`, `metadata`, `derived_feature`, `context_tag`를 분리
- 향후 EEG/EMG/IMU/robot_state/trajectory 확장을 위한 자리 확보

## frame-level 필드
- `frame_id`
- `sensor_timestamp`
- `system_timestamp`
- `context_tag`
- `scores`: context/boundary/uncertainty/novelty/total_importance
- `derived_feature`: `feature_dim`, `feature_sample`
- `raw_path`
- `storage_policy`

## event-level 필드
- `event_id`
- `trigger_frame_id`
- `start_frame_id`
- `end_frame_id`
- `importance_score`
- `reason`
- `sensor_start_ts`, `sensor_end_ts`
- `system_start_ts`, `system_end_ts`
- `pre_frame_ids`, `post_frame_ids`

## aligned export
frame를 기준으로 event 연결 정보(`event_ids`)와 aligned modality 슬롯을 함께 저장한다.
