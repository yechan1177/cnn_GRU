# 03. 모델 설계

## Spatial Encoder
- baseline: `MockSpatialEncoder`
- 실모델 경로: `YOLOSpatialEncoder`
  - 입력: 이미지 경로(`FramePacket.raw_path`)
  - 출력: 고정 길이 벡터
  - 벡터 구성: 검출 수, confidence 통계, bbox 면적 통계, 클래스 분포

## Temporal Encoder
- baseline: `GRUTemporalEncoderMock`
- 학습/추론 분리형 실모델:
  - 학습 본체: `TemporalGRUNet`
  - 추론 래퍼: `GRUTemporalEncoderTorch`

### 멀티채널 CNN-GRU 구조
- 입력 벡터를 채널 그룹으로 분리한 뒤 채널별 `1D CNN`을 먼저 적용
- 채널별 출력 특징을 시간축 기준으로 결합한 뒤 `GRU`로 맥락을 인코딩
- 최종 분류는 마지막 hidden state 대신 `time GAP(mean pooling)` 후 head에 연결
- 기본 채널 분리 예시
  - 8차원 vehicle processed dataset: `[0:2]`, `[2:4]`, `[4:6]`, `[6:8]`
  - 16차원 synthetic dataset: `global`, `vehicle`, `person`, `bike` 계열 그룹
- 설계 이유
  - 단일 벡터에 섞인 특징을 의미 단위별로 분리
  - 채널별 국소 패턴을 먼저 추출해 GRU가 시간 관계를 더 안정적으로 읽도록 구성
  - GAP 사용으로 엣지 배포 시 파라미터 수와 overfitting을 완화

### 분리된 헤드
- `context_head`: context 분류(logits)
- `boundary_head`: 이벤트 경계(logit)
- `uncertainty_head`: 불확실성(logit)

## Scoring
- `context_score`: context 확률 최대값
- `boundary_score`: temporal 경계 신호
- `uncertainty_score`: `1 - context_score`
- `novelty_score`: feature 변화량

## Auto-curation
- `high_threshold` 이상: clip 트리거
- `mid_threshold` 이상: keyframe 저장
- 낮은 중요도: discard
- ring buffer로 pre/post 구간 보존

## 설계 이유
- 초기에는 정확도 최고점보다 구조 동작 안정성/데이터 정합성이 우선
- 동일 인터페이스로 mock -> 실모델 전환이 가능하도록 구성
- 최신 구조는 multichannel CNN-GRU를 반영하여 차량/보행자/이륜차/위험 보조 특징을 채널 단위로 확장 가능하게 설계

## 2026-10 개정 사항 (TASK_051, TASK_052)

### 확인된 구현-문서 불일치
- 배포 체크포인트 `models/checkpoints/temporal_final_best.pt`의 `channel_groups`는 `[0-4], [5-8], [9-12], [13-15]`인 **인덱스 균등 분할**이다. 학습 데이터의 feature key가 `feature_N` 형태여서 의미 그룹을 찾지 못하고 기본값으로 떨어졌다. 위의 "global/vehicle/person/bike 그룹" 설명은 이 체크포인트에는 해당하지 않는다.
- v1 특징의 클래스 비율/신뢰도 값은 검출기 클래스 ID 순서(person=0, vehicle=1, bike=2)로 채워졌지만, key 이름은 `vehicle_ratio, person_ratio, bike_ratio` 순서다. 즉 `vehicle_ratio` 칸에는 실제로 **사람 비율**이 들어 있다. 체크포인트 호환을 위해 값 배치는 유지하고, 의미 그룹(`vcp.features.registry`)은 실제 값 기준으로 정의했다.
- `uncertainty_head`는 휴리스틱 중요도(1 − importance)를 회귀하도록 학습되었고, 추론 경로에서는 쓰이지 않는다. 개정 실험에서는 temperature scaling 후 예측 엔트로피를 불확실성으로 사용한다.

### 특징 모듈 분리 (`vcp.features`)
| 버전 | 용도 | 핵심 |
|---|---|---|
| v1 | 2026-03 체크포인트 호환 | 기존 계산 그대로(회귀 fixture로 검증). 프레임 차분 looming, 신규 객체 진입 시 급등 |
| v2 | 제안 | IoU 추적, Δt 정규화 EMA, 박스 폭 log 변화율 = 역 TTC, VRU 접근 지표 |

- 런타임: `spatial.feature_version: v1 | v2`
- 채널 그룹: `build_temporal_channel_groups(..., grouping="semantic"|"balanced"|"single", feature_version=...)`
  - v1 의미 그룹: global(0-4), vehicle(6,9,13,14), person(5,8,11,12), bike(7,10,11,15)
  - v2 의미 그룹: global(0-4), vehicle(5-10), vru(11-15)

### 추가 모델/헤드
- `LiteratureCNNGRUNet`(문헌형 단일채널, 공용 모듈로 이동), `LastFrameMLP`(시간정보 없는 ablation)
- `ActionHeadWrapper`: 미래 가감속(행동) 회귀 head. VLA 연계용(`docs/26`)

### 로딩 안정성
- 체크포인트 로딩 실패 시 sin 기반 mock으로 조용히 바뀌던 동작을 `temporal.fallback_to_mock`으로 제어한다. 실험/배포 설정은 `false`를 권장한다.
