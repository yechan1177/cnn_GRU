# 04. 배포 전략

## 학습/배포 분리
- 학습/실험(RTX 3080 Ti):
  - 모델 탐색, 고해상도 입력, 대규모 로그 저장
- 배포/추론(Jetson Orin Nano 8GB):
  - 경량 백본, 짧은 temporal window, I/O 최소화

## Jetson 고려사항
- detector 호출 주기와 temporal 업데이트 주기 분리
- `batch=1` 스트리밍 추론 우선
- 저장 정책을 `clip/keyframe/discard`로 제한해 쓰기 부하 절감
- 필요 시 ONNX/TensorRT 변환 경로 별도 유지

## 현재 구현 상태
- config 기반으로 profile 분리 완료
- 동일 인터페이스에서 mock/실모델 전환 가능
- 배포 최적화(TensorRT/INT8)는 후속 태스크
