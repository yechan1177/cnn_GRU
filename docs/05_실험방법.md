# 05. 실험 방법

## 실험 단위
각 실험은 `experiments/exp_XXX_*` 폴더 단위로 관리한다.

필수 파일:
- `config_snapshot.yaml`
- `notes.md`
- `metrics.csv`
- `result_summary.md`

## 기록 규칙
- 설정, 코드 버전, 결과 파일 경로를 함께 저장한다.
- 검증되지 않은 수치는 기록하지 않는다.
- 표/그림/스크린샷은 `artifacts/` 하위에 분류 저장한다.

## 권장 절차
1. config 확정
2. 실행/학습 수행
3. 결과 파일 존재 확인
4. 실험 요약 작성
5. TODO/TASK 반영
