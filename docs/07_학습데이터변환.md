# 07. 학습 데이터 변환 가이드

## 목적
- `outputs/`에 생성된 run 데이터를 학습 가능한 시퀀스 샘플로 변환한다.

## 실행
```bash
python -m vcp.tools.convert_dataset --run-id <run_id> --window-size 6 --val-ratio 0.2
```

`run_id`를 생략하면 `outputs/runs` 기준 최신 run을 자동 선택한다.

## 출력 경로
- `data/processed/dataset_<run_id>/`

## 생성 파일
- `frame_table.csv`
- `event_table.csv`
- `samples_all.jsonl`
- `train.jsonl`
- `val.jsonl`
- `label_map.json`
- `analysis.json`
- `dataset_manifest.json`

## 설계 이유
- frame/event 원본과 학습 샘플을 분리 저장해, 재현성과 추적성을 유지한다.
- split은 시간 순서 기반으로 나눠 시퀀스 누수 가능성을 줄인다.

## 현재 한계
- baseline exporter는 full feature 대신 feature sample(일부 차원)만 저장한다.
- 실제 모델 학습 전 단계에서 full feature 저장 옵션을 추가하는 것이 권장된다.
