# 10. race.mp4 실시간 테스트 가이드

## 목적
`data/raw/videos/race.mp4`를 입력으로, 현재 구축된
YOLO Spatial + Temporal GRU 파이프라인을 실시간으로 검증한다.

## 실행 명령
실시간 창 표시:
```bash
vcp-video-demo --video data/raw/videos/race.mp4 --config configs/runtime_rtx3080ti_yolo_gru.yaml --display --save-video
```

헤드리스/원격 환경(창 미표시):
```bash
vcp-video-demo --video data/raw/videos/race.mp4 --config configs/runtime_rtx3080ti_yolo_gru.yaml --no-display --save-video --max-frames 300
```

## 화면 오버레이 정보
- YOLO 바운딩 박스 + 클래스 + confidence
- frame 번호
- context tag
- 상위 context 확률(top-3) 막대
- 저장 정책(policy: clip/keyframe/discard)
- 점수(context/boundary/uncertainty/novelty/total)
- 누적 event 수
- 실시간 FPS

## 결과 저장 경로
- run 요약: `outputs/runs/<run_id>/race_demo_summary.json`
- 오버레이 영상: `outputs/runs/race_video_demo_preview_*.mp4`
- 스크린샷: `artifacts/screenshots/race_demo_*.jpg`
- 실험 요약: `experiments/exp_006_race_video_demo/`

## 참고
- 창 표시 모드에서는 `q` 키 입력 시 즉시 종료한다.
- 현재 threshold 기준으로 event가 적게 검출될 수 있다. 필요 시 `configs/...`의 scoring 임계값을 조정한다.
