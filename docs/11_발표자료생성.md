# 11. 발표자료 생성 가이드

## 목적
race.mp4 실시간 검증 결과를 발표 가능한 PPT로 자동 생성한다.

## 생성 명령
권장(`slides` 스킬, PptxGenJS):
```bash
node artifacts/presentations/slides_src/build_vcp_race_demo_slides.js
```

호환(`python-pptx`):
```bash
.\.venv\Scripts\python.exe scripts/build_race_ppt.py
```

## 출력 파일
- `artifacts/presentations/vcp_race_demo_report_slideskill_YYYYMMDD.pptx`
- `artifacts/presentations/vcp_race_demo_talk_track_slideskill.md`
- `artifacts/presentations/presentation_manifest_slideskill.json`

## 포함 내용
- 프로젝트 목적/구조
- YOLO 및 Temporal 학습 요약
- race.mp4 실시간 실행 결과 수치
- 실행 화면 스크린샷
- 한계 및 다음 개선 항목
