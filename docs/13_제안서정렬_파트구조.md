# proposal_v2 정렬 파트 구조

## 목적
- `proposal/source/proposal_v2.md`의 추진 구조에 맞춰 코드/실험/산출물 접근 경로를 통일한다.
- 실행 코드는 유지하면서, 제안서/논문 작성 시 탐색 비용을 줄인다.

## 파트 정의
1. 입력 + 온디바이스 비전 특징 추출
2. 시계열 맥락 인식
3. 점수화/이벤트 경계
4. 자동 정제(ring buffer)
5. 정렬 데이터셋 export
6. 검증/발표/제안서

## 코드 구조 변경
- 신규 진입점 패키지: `src/vcp/parts/`
- 파이프라인 import는 `vcp.parts`를 우선 사용
- 기존 `src/vcp/components/`는 호환성을 위해 유지

## 연구 활용 폴더
- `research/parts/01_온디바이스비전특징추출/`
- `research/parts/02_시계열맥락인식/`
- `research/parts/03_점수화이벤트경계/`
- `research/parts/04_자동정제/`
- `research/parts/05_정렬데이터셋export/`
- `research/parts/06_검증발표제안서/`

각 파트 `README.md`에는 다음이 포함된다.
- 관련 코드
- 관련 설정
- 관련 실험
- 관련 산출물

## 운영 원칙
- 새 실험을 추가할 때, 해당 파트 README의 경로 인덱스를 함께 갱신한다.
- 구현 변경 시 최소 1개 이상 문서(`tasks`, `README`, `docs`)를 동시 갱신한다.
