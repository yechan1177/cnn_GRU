# 수동 맥락 라벨링 데이터셋 가이드

## 목적
기존 `Temporal GRU` 학습 데이터는 `YOLO 박스 통계 -> dominant class` 기반의 약한 라벨을 사용했다.
이 방식은 실제 맥락보다 객체 이름에 더 강하게 끌려서 `people` 같은 라벨 편향이 생기기 쉬웠다.

따라서 이 가이드는 영상 구간 단위의 수동 맥락 annotation을 만들고, 이를 detector feature와 결합해 시계열 학습 데이터셋으로 변환하는 절차를 정의한다.

## 기본 원칙
- 라벨은 객체명보다 `상황명` 중심으로 정의한다.
- annotation 단위는 frame 하나가 아니라 `segment(구간)`이다.
- 급정지 계열은 `front_vehicle_follow -> brake_warning -> hard_brake_risk -> post_brake_recovery` 흐름으로 세분화한다.
- `brake_warning`는 중앙 ROI에서 전방 박스가 짧은 프레임 사이 빠르게 커지는 구간이다.
- `hard_brake_risk`는 박스가 더 급격히 커지거나 움직임이 둔화/정지하는 구간이다.

## 권장 라벨
- `normal_drive`
- `front_vehicle_follow`
- `brake_warning`
- `hard_brake_risk`
- `post_brake_recovery`
- `dense_traffic`

## feature source
현재 detector feature는 아래 신호를 포함한다.
- `det_norm`, `mean_conf`, `max_conf`, `mean_area`, `area_var`
- `vehicle_ratio`, `person_ratio`, `bike_ratio`
- `vehicle_conf`, `person_conf`, `bike_conf`
- `roi_risk`: 중앙 ROI 위험도
- `motion_delta`: 프레임 간 ROI 변화량
- `center_closeness`: 중앙 정렬 정도
- `looming_score`: 중앙 ROI 객체 급팽창 정도
- `occlusion_score`: 전방 객체가 커진 뒤 motion이 둔화되는 정지성 신호

## 변환 명령
```bash
vcp-build-context-dataset --annotations-root data/annotations/context --runs-root outputs/runs --dataset-name manual_context_yolo3cls_t045 --window-size 8 --val-ratio 0.2
```

## 현재 한계
- annotation 수가 아직 적고 `draft` 상태다.
- `hard_brake_risk`, `brake_warning` 구간 표본이 매우 적다.
- 추적기 기반 TTC, optical flow, 실제 IMU는 아직 포함되지 않았다.
