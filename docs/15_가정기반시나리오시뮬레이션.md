# 가정 기반 주행 시나리오 시뮬레이션 가이드

## 목적
실제 차량 주행 시뮬레이터가 없는 상태에서도, 다양한 주행 상황을 가정해 `Temporal GRU`의 출력값을 프레임 단위로 확인할 수 있도록 한다.

현재 기능은 `실제 영상 추론`이 아니라 `상황 -> 특징 벡터 시퀀스 -> 맥락 확률` 경로를 재현하는 도구이다.

## 사용 모델
- 체크포인트: `experiments/exp_007_synthetic_temporal_10context/runs/gru_10ctx_synth_e12_h96/checkpoints/best.pt`
- 데이터셋 정의: `data/processed/dataset_synthetic_temporal_10ctx_20260320_214500/manifest.json`

즉 현재는 `합성 10맥락`용으로 학습된 GRU를 사용한다.

## 지원 시나리오
- `front_vehicle_brake`
- `pedestrian_crossing_event`
- `pedestrian_dash_event`
- `bike_cut_in_event`
- `dense_alley_mix`
- `urban_multi_event`

## 실행
전체 시나리오 실행:
```bash
vcp-simulate-scenarios --scenario all
```

단일 시나리오 실행:
```bash
vcp-simulate-scenarios --scenario front_vehicle_brake
```

## 출력
기본 저장 경로:
- `experiments/exp_010_synthetic_scenario_probe/runs/<run_id>/`

시나리오별 파일:
- `frame_probe.jsonl`: 프레임별 출력
- `frame_probe.csv`: 표 형태 출력
- `phase_definition.jsonl`: 시나리오 phase 정의
- `summary.json`: 시나리오 요약

전체 요약:
- `overall_summary.json`

## 주요 출력 컬럼
- `gt_context`: 가정한 phase의 정답 컨텍스트
- `pred_top1`: 모델이 가장 높게 본 컨텍스트
- `pred_top1_prob`: 해당 확률
- `boundary_score`: 이벤트 전환 강도
- `total_importance`: 최종 중요도
- `roi_risk`, `motion_delta`, `center_closeness`, `looming_score`, `occlusion_score`: 핵심 feature 값

## 해석
예를 들어 `front_vehicle_brake`는 아래 흐름으로 구성된다.
- `clear_cruise`
- `front_vehicle_follow`
- `front_vehicle_close`
- `hard_brake_risk`
- `clear_cruise`

따라서 phase가 바뀌는 구간에서 `boundary_score`가 올라가고, `hard_brake_risk` 구간에서 `total_importance`와 `looming_score`가 함께 커지는지를 확인하면 된다.

## 실제 YOLO 가중치와의 관계
현재 도구는 실제 시뮬레이터 프레임이 없기 때문에, `학습된 YOLO 백본/검출기 가중치`를 직접 사용하지 않는다.

하지만 실제 차량 시뮬레이터가 다음 중 하나를 제공하면 앞단 교체가 가능하다.
- 프레임 이미지
- 영상 파일
- 프레임별 검출 결과

그 경우:
- 앞단: 학습된 YOLO 가중치로 검출
- 중단: feature packing
- 뒷단: 현재 Temporal GRU / scoring 재사용

즉 현재 도구는 `시뮬레이터 연결 전 단계의 가정 기반 probe`로 보면 된다.
