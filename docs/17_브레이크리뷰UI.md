# 브레이크 리뷰 UI

## 목적
- `outputs/runs`에 저장된 브레이크 전환 추론 결과를 프레임 단위로 검수한다.
- `normal_drive`, `front_vehicle_follow`, `brake_warning`, `hard_brake_risk`, `post_brake_recovery`, `dense_traffic` 구간을 사람이 직접 다시 자른다.
- reviewed annotation을 `data/annotations/context/*_reviewed_context_segments.jsonl`로 저장한다.

## 실행
가장 간단한 실행:

```bash
launchers\07_brake_review_ui.bat
```

직접 실행:

```bash
vcp-brake-review
```

특정 run과 영상 지정:

```bash
vcp-brake-review --run-dir outputs/runs/stopcar_braking_expanded_t045_demo_20260324_115331 --video data/raw/videos/stopcar.mp4
```

프리뷰 이미지 저장 후 종료:

```bash
vcp-brake-review --export-preview preview.jpg
```

## 기본 동작
- 최신 `braking` run을 자동으로 찾는다.
- run의 `frame_records.jsonl`을 읽는다.
- 우측 패널에 아래 값을 표시한다.
  - 예측 맥락
  - total importance
  - boundary
  - `roi_risk`
  - `motion_delta`
  - `center_closeness`
  - `looming_score`
  - `occlusion_score`

## 검수 방법
1. `a`, `d` 또는 `j`, `l`로 프레임을 이동한다.
2. 숫자 키 `1~6`으로 라벨을 고른다.
3. 시작 프레임에서 `z`, 끝 프레임에서 `x`를 누른다.
4. boundary로 남길 프레임에서 `b`를 누른다.
5. `c`를 누르면 현재 라벨로 구간이 추가된다.
6. `w`를 누르면 reviewed annotation이 저장된다.

## 키 매핑
- `space`: 재생/정지
- `a`, `d`: 1프레임 이동
- `j`, `l`: 30프레임 이동
- `1~6`: 라벨 선택
- `z`: 구간 시작
- `x`: 구간 끝
- `b`: boundary 프레임 토글
- `c`: 구간 추가
- `r`: 마지막 구간 삭제
- `w`: annotation 저장
- `q`: 종료

## 저장 결과
- 기본 저장 경로:
  - `data/annotations/context/<video_stem>_reviewed_context_segments.jsonl`

예:
- `data/annotations/context/stopcar_reviewed_context_segments.jsonl`

## 주의
- reviewed 파일은 기존 draft annotation을 자동으로 덮어쓰지 않는다.
- `build_context_dataset.py`를 다시 실행해 reviewed annotation을 학습 데이터에 반영해야 한다.
