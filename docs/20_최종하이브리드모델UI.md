# 최종 하이브리드 모델 UI

## 목적
- 저장된 braking run을 다시 열어 순수 모델 결과와 하이브리드 최종 결과를 함께 확인한다.
- 현재 프레임에서 어떤 규칙이 발동했는지 `rule trigger reason`까지 확인한다.

## 실행 파일
- 배치 파일: `launchers/08_final_hybrid_model_ui.bat`
- Python 진입점: `python -m vcp.tools.final_hybrid_model_ui`

## 기본 실행
```bat
C:\yolstm\launchers\08_final_hybrid_model_ui.bat
```

## 특정 run 지정
```bat
C:\yolstm\launchers\08_final_hybrid_model_ui.bat --run-dir C:\yolstm\outputs\runs\stopcar_braking_expanded_t045_demo_20260324_115331 --video C:\yolstm\data\raw\videos\stopcar.mp4
```

## 화면 표시 항목
- 현재 프레임 번호
- 저장된 run tag
- 순수 모델 top1 context
- 하이브리드 최종 context
- 최종 결정 이유(`decision reason`)
- boundary score
- `brake_warning`, `hard_brake_risk`, `front_vehicle_follow` 확률
- `roi_risk`, `center_closeness`, `looming_score`, `occlusion_score`, `motion_delta`
- `warn_reason`, `hard_reason`
- 최근 120프레임 기준 추이 그래프

## 조작 키
- `space`: 재생/정지
- `a`, `d`: 1프레임 이동
- `j`, `l`: 30프레임 이동
- `q`: 종료

## 규칙 이유 표시 예시
- `promote:warn_feat(roi+center+looming+motion_rise)`
- `promote:hard_signal(boundary+hard_prob)`
- `demote:weak_warn->follow`
- `pure:hard_brake_risk`

## 참고
- detector를 다시 돌리지 않고 `frame_records.jsonl`에 저장된 16차원 feature vector를 기준으로 후단 판단을 다시 계산한다.
- 하이브리드 규칙 파라미터는 `configs/hybrid_rule_params.json`에서 불러온다.
