# 벤치마크 실행 로그 및 그래프 출력

## 변경 목적
- `benchmark_context_models` 실행 중 단계별 진행 상태를 콘솔에서 바로 확인할 수 있도록 개선한다.
- 학습 이력과 하이브리드 튜닝 과정을 그래프로 저장하여 결과 해석을 쉽게 만든다.

## 추가된 출력
- 단계별 진행 로그
  - 데이터셋 로드
  - 기본 규칙형 baseline 평가
  - 문헌형 CNN-GRU epoch별 학습 진행
  - 제안 모델 순수 평가
  - 하이브리드 룰 게이트 튜닝 진행 및 best 갱신
- 그래프 파일
  - `context_model_benchmark_metrics.png`
  - `literature_training_curves.png`
  - `hybrid_tuning_curves.png`
- 이력 파일
  - `literature_history.json`
  - `hybrid_tuning_history.json`

## 사용 예시
```powershell
cd C:\yolstm
.\.venv\Scripts\python.exe -m vcp.tools.benchmark_context_models --dataset-dir data/processed/dataset_manual_context_braking_expanded_feat16_t045_20260324_115253 --device cuda:0 --epochs 24 --batch-size 256 --hidden-dim 96 --cnn-channels 24 --project experiments/exp_017_hybrid_rule_gate_benchmark/runs --name context_model_benchmark_hybrid_v2
```

그래프 창만 끄고 파일만 저장하려면 아래 옵션을 추가한다.

```powershell
--no-show-plots
```

## 결과 위치
- 실행 폴더: `experiments/exp_017_hybrid_rule_gate_benchmark/runs/<name>/`
- 루트 산출물:
  - `context_model_benchmark_actual_table.csv`
  - `context_model_benchmark_actual_table.md`
  - `context_model_benchmark_metrics.png`
