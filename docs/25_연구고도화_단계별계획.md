# 연구 고도화 단계별 계획 (2026-10 개정)

## 배경
2026-03 버전(논문 제출본) 점검 결과, 다음 문제가 확인되었다.

| 구분 | 문제 | 영향 |
|---|---|---|
| 데이터 | 영상 6개 / 수동 구간 35개(전부 draft), 브레이크 표본 수십 개 | 통계적 근거 부족 |
| 평가 | 같은 영상 내부 구간 분할, 검증셋으로 임계값 튜닝 후 같은 검증셋 보고, 학습 영상을 "실측"으로 재사용 | 성능 과대평가(누수) |
| 라벨 | ROI/looming 피크 기반 bootstrap 라벨을 같은 특징의 룰 게이트로 평가 | 순환 구조 |
| 지표 | 정확도(=다수 클래스 비율에 근접) 중심, macro-F1 미보고 | 비교 해석 왜곡 |
| 구조 | 배포 체크포인트 채널 그룹이 의미 그룹이 아닌 인덱스 균등 분할 | 문서 주장과 불일치 |
| 특징 | looming/motion이 프레임 차분 기반이라 FPS 의존, 신규 객체 진입 시 looming 급등 | 배포 FPS 변화에 취약 |
| 배포 | Jetson 설정이 mock 전용, 실기기 측정 없음, CUDA 하드코딩 실행기 | 온디바이스 주장 근거 부족 |
| 저장소 | 가상환경 파일 커밋, 한글 깨짐, 체크포인트 로딩 실패 시 mock으로 조용히 대체 | 재현성/신뢰성 저하 |

## 단계별 계획

### 1단계: 저장소 정리 (TASK_050)
- [ ] `.venv_readme_check/` 추적 해제, `.gitignore` 재설계(생성물 무시 + 요약 결과/논문 원고는 추적)
- [ ] `run_final_model.py` 깨진 한글 복구

### 2단계: 코드 결함 수정 (TASK_051)
- [ ] 실행기 headless/CLI화 (`--source`, `--device auto`, `--no-display`, `--save-video`, `--output-jsonl`)
- [ ] temporal 체크포인트 로더: 문헌형 구조 지원, 실패 시 조용한 mock 대체 금지(옵션화)
- [ ] 채널 그룹: feature key가 일반 이름일 때도 특징 버전 기반 의미 그룹 적용, `--channel-grouping` 옵션
- [ ] 하이브리드 룰 게이트: 특징 인덱스 하드코딩 제거(key 이름 기반)

### 3단계: 특징 v2 (TASK_052)
- [ ] 검출 박스 → 특징 계산을 순수 모듈(`vcp.features`)로 분리 (v1은 기존 수치 그대로 재현)
- [ ] v2: 시간(Δt) 정규화 변화율, IoU 기반 선행 차량/보행자 추적, scale-rate 기반 역 TTC
- [ ] 런타임 `spatial.feature_version` 설정 지원

### 4단계: 데이터 생성 (TASK_053)
- [ ] 물리 기반 합성 주행 시나리오 생성기(`vcp.sim`): IDM 자차 제어, 선행차 급제동/끼어들기/보행자 횡단/정체/정지-출발
- [ ] 핀홀 카메라 투영 + 검출기 노이즈 모델(미검출/박스 흔들림/오검출/클래스 혼동/피치 흔들림)
- [ ] 라벨은 GT 물리량(TTC, 요구 감속도, 자차 감속도)에서 생성 → 특징과 독립(순환 제거)

### 5단계: 실데이터 수집 (TASK_054)
- [ ] 공개 실주행 영상(comma.ai speedchallenge, 20fps, 프레임별 속도) 수집 스크립트
- [ ] 3클래스 YOLO 검출 결과 JSONL 추출
- [ ] 속도 센서 기반 자차 운동 상태 라벨(정지/제동/가속/정속) 생성 → 시각 특징과 독립

### 6단계: 자동 실험 (TASK_055)
- [ ] 에피소드/시간 블록 단위 분할, 검증셋으로만 튜닝, 테스트셋은 최종 1회 평가
- [ ] 다중 시드, macro-F1, 클래스별 F1, 이벤트 단위 recall/지연, 분당 오경보, 라벨 깜빡임, bootstrap 95% CI
- [ ] 비교군: 다수 클래스, 룰 단독, MLP(시간 정보 없음), GRU, 단일채널 CNN-GRU, 균등분할 멀티채널, 의미 멀티채널(제안)
- [ ] ablation: 특징 v1/v2, 하이브리드 게이트, 손실 함수, 후처리 평활화
- [ ] 강건성: FPS 변화(학습 15fps → 10/30fps), 검출 노이즈 증가
- [ ] 보정/불확실성: temperature scaling, ECE, 오류 탐지 AUROC, 큐레이션 예산 대비 이벤트 회수율
- [ ] 지연시간: PyTorch / ONNX Runtime CPU 측정(클라우드), Jetson은 미측정으로 명시

### 7단계: 논문 초안 (TASK_056)
- [ ] 실험 결과 JSON → 논문 원고(`paper/manuscript_ko.md`) 표 자동 채움
- [ ] 한계와 미검증 항목(Jetson 실측, 실차 CAN 브레이크 신호) 명시

### 8단계: 사용자 환경 필요(백로그)
