# 세 모델 동시 비교 실행

## 목적
- 같은 영상을 세 모델에 동시에 통과시켜 프레임별 출력값을 비교한다.
- 결과를 CSV, JSON, Markdown, PNG 그래프로 저장한다.
- 감지된 상황에 대해 스크린샷과 짧은 클립을 자동 저장한다.

## 실행 파일
- `run_compare_three_models.py`

## 실행 방법
```powershell
cd C:\yolstm
.\.venv\Scripts\python.exe run_compare_three_models.py
```

## 입력 변경
- `USE_WEBCAM`
- `WEBCAM_INDEX`
- `VIDEO_SOURCE`
- `MAX_FRAMES`

위 네 항목은 파일 상단 설정 블록에서 바꾼다.

## 저장 산출물
- `artifacts/comparisons/<video_stem>_three_model_compare/frame_comparison.csv`
- `artifacts/comparisons/<video_stem>_three_model_compare/summary.json`
- `artifacts/comparisons/<video_stem>_three_model_compare/summary.md`
- `artifacts/comparisons/<video_stem>_three_model_compare/comparison_plot.png`
- `artifacts/comparisons/<video_stem>_three_model_compare/event_records.json`
- `artifacts/comparisons/<video_stem>_three_model_compare/screenshots/`
- `artifacts/comparisons/<video_stem>_three_model_compare/clips/`

## 비교 대상
- `YOLO + rule`
- `literature CNN-GRU`
- `final hybrid`

## 그래프 구성
- 세 모델 라벨 비교
- warning 계열 신호 비교
- hard brake 계열 신호 비교
- boundary 및 looming 비교

## 이벤트 저장 기준
- 세 모델 중 하나라도 `brake_warning` 또는 `hard_brake_risk`를 출력하면 이벤트 후보로 기록한다.
- 기본적으로 현재 프레임 기준 앞 `15`프레임, 뒤 `20`프레임을 포함한 클립을 저장한다.
