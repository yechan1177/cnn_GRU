# 실험 프로토콜과 자동 실험 스위트 (2026-10)

## 원칙
1. **분할 단위**: 합성 데이터는 에피소드 단위, 단일 장시간 실영상은 10개 연속 시간 블록 단위로 나눈다. 같은 에피소드/블록의 창은 한 분할에만 속한다. 블록 경계 ±1초는 평가에서 제외한다.
2. **튜닝은 검증셋에서만**: 룰 임계값, 하이브리드 게이트, temperature, EMA 계수, 경계 임계값을 검증셋에서 고르고 테스트셋에는 고정 적용한다.
3. **라벨 독립성**: 합성 데이터는 GT 물리량, 실영상은 속도 센서에서 라벨을 만든다. 모델 입력 특징은 라벨 생성에 쓰지 않는다.
4. **반복**: 합성은 시드 3개, 실영상은 10-fold. 평균 ± 표준편차와 bootstrap 95% CI를 보고한다.
5. **수치 출처**: 논문/문서의 모든 수치는 `experiments/exp_100_paper_suite/summary/*.json`에서 자동 생성한다.

## 지표
| 지표 | 정의 |
|---|---|
| macro-F1 | 정답에 존재하는 클래스 평균 F1 |
| 제동 이벤트 recall | GT 제동 계열 연속 구간 중, 시작 0.5초 전~종료 사이에 한 번이라도 제동 계열 예측이 있는 비율 |
| 검출 지연 | 첫 예측 시각 − GT 시작 시각(음수 = 선행) |
| 오경보/분 | GT 이벤트 ±1초와 겹치지 않는 2프레임 이상 예측 구간 수 / 분 |
| 라벨 전환/분 | 예측 라벨이 바뀌는 횟수(깜빡임) |
| 경계 F1 | ±2프레임 허용 |
| ECE | 15구간 보정 오차 |
| 오류 탐지 AUROC | 예측 엔트로피로 오분류 프레임을 구분 |
| 큐레이션 회수율 | 저장 예산 k%로 고른 프레임/클립이 포함한 제동 프레임·이벤트 비율 |

## 실행
```bash
bash scripts/run_paper_suite.sh            # 전체(데이터 수집 → 실험 → 리포트 → 원고)
bash scripts/run_paper_suite.sh --quick    # 스모크 테스트
# 개별 단계
PYTHONPATH=src python -m vcp.experiments.run_suite synthetic|comma|vla|latency|report
python scripts/build_paper.py
```
