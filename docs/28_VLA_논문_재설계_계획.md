# 28. VLA 연계 논문 재설계 계획 (2026-10)

## 0. 범위 결정
- 제외: Jetson 실측, 기존 6개 영상 재평가(사용자 결정).
- 목표: "경량 맥락 모델이 VLA 학습 데이터를 고른다"는 주장을 **하위 VLA 정책의 실제 성능(폐루프 포함)** 으로 검증하는 SCI급 논문.
- 문제의식은 기존 논문(비전 인식-맥락 연계로 VLA용 멀티모달 데이터셋 자동 구축)을 유지하되, 미해결 문제를 아래처럼 재정의한다.

## 1. 문제 재정의
### 연구 질문
> 현장 장치(차량·이동로봇)가 저장·전송 예산 안에서 데이터를 고를 때, 무엇을 남겨야 그 데이터로 학습한 VLA 정책이 드물지만 안전에 결정적인 상황에서 실패하지 않는가?

### 기존 방법의 미해결 문제(서론 근거, 문헌 에이전트가 인용 검증)
| 계열 | 대표 | 미해결 문제 |
|---|---|---|
| 오프라인 로봇 데이터 큐레이션 | DemInf, CUPID, DataMIL, Re-Mix, SCIZOR, Demo-SCORE | 전체 데이터 저장·정책 학습·롤아웃이 필요. 수집 시점(엣지)에는 쓸 수 없다. 에피소드 단위 선별이 많다 |
| 자율주행 데이터 엔진·능동학습 | 트리거 기반 수집, 불확실성 선별, coreset | 대형 모델이나 수작업 트리거에 의존. 하위 정책(특히 폐루프) 성능으로 거의 검증하지 않는다 |
| 자동 언어 주석 | NILS, ECoT, DIAL, VLM 캡셔닝 | 대형 VLM이 필요해 엣지에서 못 쓴다. 물리량(TTC 등)과 정렬된 서술이 아니다 |
| 경량·이중 시스템 VLA | SmolVLA, TinyVLA, GR00T N1, Hi Robot 등 | 추론 효율에 집중하고, 데이터 수집 측 경량 모듈은 다루지 않는다 |
| 개루프 평가 | 행동 MSE·정확도 | 폐루프 성능과 상관이 약하다(Codevilla 2018 등) |

### 요구사항
- R1: 수집 시점·온디바이스 실시간(ms 단위)으로 동작해야 한다.
- R2: 정책 학습 없이 희소 위험에 민감한 신호를 내야 한다(물리 기반 특징 + 시간 맥락).
- R3: 관측-언어-행동 정렬 주석을 자동으로 붙여야 한다.
- R4: 표준 형식(LeRobot)으로 내보내야 한다.
- R5: 하위 VLA 정책 성능(개루프 + 폐루프)으로 검증해야 한다.

## 2. 방법(제안 시스템)
1. 맥락 점수기: 기존 멀티채널 CNN-GRU(v2/v1v2 특징)를 작은 "부트스트랩 라벨 셋"(기존 합성 700 에피소드)으로 학습한다.
2. 클립 점수: `s = P(경고)+P(강한 제동)` + λ·엔트로피(불확실성).
3. 예산 선별: 점수 상위 클립에 (1-ρ) 예산을 쓰고, ρ 예산은 무작위 저장소(reservoir)로 남겨 정상 상황을 보존한다. λ, ρ는 검증 풀에서만 고른다.
4. 언어 정렬: 에피소드 지시문(주행 스타일·목표 속도) + 프레임 서술(맥락·TTC 템플릿).
5. 내보내기: LeRobot v2 구조.

## 3. 검증 설계
### 하위 정책(VLA-lite)
- 입력: 렌더링 영상 2프레임(64×64, t와 t−2) + 지시문 토큰 + 자차 속도.
- 출력: 미래 가속도 청크 H=8.
- 구조: 시각 CNN과 언어 임베딩(FiLM 조건화) + MLP. 처음부터 학습한다(사전학습 가중치 다운로드 불가 환경).
- 통제: 모든 조건에서 경사 단계 수·배치·학습률·구조·평가 시드를 고정한다. 데이터 양만 예산으로 바뀐다.

### 데이터
- 점수기 학습: 기존 `main_15fps_mid`(700 에피소드)를 쓴다. 풀과 시드가 겹치지 않는다.
- 큐레이션 풀: 스타일 지시문이 붙은 새 주행 에피소드 1200개(시드 100000+).
- 하이퍼파라미터 검증: 70개(시드 150000+).
- 폐루프 테스트: 140개(시드 200000+, 시나리오×스타일 균형).
- 로봇(AMR): 풀 600개와 테스트 72개.
- 실주행(comma): 블록 교차검증, 64×64 프레임, 개루프 평가.

### 비교 선별법
| 방법 | 내용 |
|---|---|
| full | 100% 데이터(참고 상한) |
| random | 무작위 클립 |
| uniform | 등간격 클립 |
| action_trigger | 자차 감속도 트리거(CAN 기반 데이터 엔진 관행) |
| rule_ittc | 물리 규칙(역 TTC 특징) |
| uncertainty | 엔트로피만 사용 |
| coreset | 특징 k-center |
| offline_loss | 전체 데이터로 정책을 학습한 뒤 손실 상위를 고름(오프라인·정책 의존, 비교 상한 성격) |
| oracle | GT 위험 라벨(특권 정보) |
| ours | 맥락 점수 + 불확실성 + 저장소 |

- 예산: 5%, 10%, 20%.
- 시드: 3개. 파일럿에서 측정한 분산으로 최종 확정한다.

### 지표
- 폐루프
  - 충돌 에피소드 비율, 최소 TTC, 위험 시나리오 성공률
  - 지시 준수: 목표 속도 오차, 추종 시 시간 headway 대 지시값
  - 승차감: RMS jerk
  - 진행률
- 개루프: 전체·위험 구간 행동 MAE.
- 선별 품질: 이벤트 회수율, 선택 데이터 라벨 분포 엔트로피.
- 비용: 프레임당 점수 계산 시간(온디바이스) 대 오프라인 방법 계산량.

### 변수 측정·통제(실험 전 단계, 논문 5.1절)
1. 풀 분포 측정: 맥락별 비율, 이벤트 희소도, 시나리오·스타일 분포.
2. 시드 분산 측정: full과 random-20%를 각 3시드로 돌려 표준편차를 구하고, 최소 검출 효과를 계산한다.
3. 학습 단계 수 결정: full 데이터 학습 곡선이 수렴하는 지점에서 고정한다.
4. 교란 변수 통제: 클립 길이, 경사 단계, 평가 시드, 지시문 분포, 렌더링 노이즈, 점수기 학습 데이터 분리.
