# 28. 세 모델 정의 재구성

## 모델 정의
본 저장소의 최종 비교 모델은 아래 세 가지로 고정한다.

1. `YOLO + 순간 규칙`
   - 입력: 현재 프레임 YOLO 검출 박스
   - 판단 기준: 사람/이륜차/차량 박스가 중앙 시야 ROI에 들어왔는지, 박스 중심이 얼마나 중앙에 가까운지, 현재 프레임에서 얼마나 크게 보이는지
   - 특징: feature vector와 시계열 모델을 사용하지 않는다.

2. `CNN-GRU 단독`
   - 입력: 현재 프레임 기준 16차원 순간 특징 벡터의 최근 8프레임 시퀀스
   - 특징: 순간 feature 자체는 시간 파생값을 포함하지 않으며, 변화량 학습은 GRU가 담당한다.
   - 학습 데이터: 3번 모델과 동일한 pseudo-label dataset을 사용한다.

3. `CNN-GRU + 순간 규칙 보정`
   - 입력: 2번 모델과 동일한 CNN-GRU 출력
   - 보정 신호: 1번 모델의 raw detection 규칙 결과
   - 특징: temporal 확률과 현재 프레임 규칙을 함께 사용해 최종 이벤트 태그를 조정한다.

## 순간 특징 벡터 구성
현재 temporal 입력 feature는 모두 현재 프레임에서만 계산한다.

- `det_norm`
- `mean_conf`
- `max_conf`
- `mean_area`
- `area_var`
- `vehicle_ratio`
- `person_ratio`
- `bike_ratio`
- `vehicle_conf`
- `person_conf`
- `bike_conf`
- `roi_risk`
- `center_closeness`
- `roi_mean_area`
- `roi_count_norm`
- `roi_vertical_bias`

즉 `motion_delta`, `looming`, `occlusion`과 같은 직전 프레임 기반 파생 특징은 제거했고, 시간 변화는 sequence 전체를 통해 학습한다.

## 공통 학습 데이터셋
2번과 3번 모델은 아래 동일 데이터셋을 사용한다.

- `data/processed/dataset_rule_context_instant_feat16_v2_20260327_162111`

이 데이터셋은 새 순간 feature run들을 바탕으로 자동 pseudo-label을 부여해 생성했다.

## 실제 문맥 일치 확률 수식
실제 이벤트 여부는 사용자가 직접 판단해야 하므로, 본 저장소에서는 수식만 제공한다.

\[
P_{ctx} = \frac{N_{match}}{N_{total}}
\]

- `N_match`: 사용자가 실제 상황과 일치한다고 판정한 프레임 수
- `N_total`: 평가 대상 전체 프레임 수

## 논문용 정량 지표 위치
세 모델 비교 산출물은 아래 경로에 저장된다.

- `artifacts/comparisons/<video_stem>_three_model_compare/summary.json`
- `artifacts/comparisons/<video_stem>_three_model_compare/frame_comparison.csv`
- `artifacts/comparisons/<video_stem>_three_model_compare/comparison_plot.png`

`summary.json`에는 아래 지표가 포함된다.

- `A_det`: detector 공통 mAP50
- `T_inf_rule_ms`: 1번 모델 평균 추론 시간
- `T_inf_temporal_ms`: 2번 모델 평균 추론 시간
- `T_inf_hybrid_ms`: 3번 모델 평균 추론 시간
- `N_param_rule`: 1번 모델 전체 파라미터 수
- `N_param_temporal`: 2번 모델 전체 파라미터 수
- `N_param_hybrid`: 3번 모델 전체 파라미터 수
