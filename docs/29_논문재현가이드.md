# 29. 논문 재현 가이드

## 목적
이 문서는 `온디바이스기반_연속_상황_인지를_위한_경량_YOLO-GRU_하이브리드_모델` 초안 기준으로 저장소를 다시 실행하고, 세 모델 비교 결과와 논문용 표/그래프를 재생성하는 절차를 정리한다.

## 재현 범위
현재 저장소는 아래 범위를 재현 대상으로 둔다.

1. 세 모델 비교 실행
   - `YOLO + 규칙`
   - `CNN-GRU 단독`
   - `CNN-GRU + 규칙`
2. 논문에 사용한 클래스 분포 그래프 재생성
3. 엔드투엔드 추론 시간과 파라미터 수 비교 산출

전체 학습 데이터셋과 원본 영상은 저장소에 포함하지 않으므로, 학습을 처음부터 다시 수행하려면 별도 데이터 준비가 필요하다. 반면 논문 결과 확인과 비교 실험은 포함된 체크포인트로 재현할 수 있다.

## 필수 환경
- Python 3.10 이상
- CUDA 11.8 이상 권장
- Windows PowerShell 기준 경로 사용

## 실행 전 준비
### 1. 가상환경 생성
```powershell
cd C:\yolstm
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install -e .
```

### 2. 입력 영상 준비
아래 영상 파일을 `data/raw/videos/` 경로에 배치한다.

- `people_braking.mp4`
- `stopcar.mp4`
- `rainy_stopcar.mp4`
- `stopcar1.mp4`
- `stopcar2.mp4`
- `race.mp4`

기본 비교 실행은 `people_braking.mp4`를 우선 사용한다. 다른 영상을 쓰고 싶다면 루트 실행 파일 상단의 `VIDEO_SOURCE`를 변경하면 된다.

## 논문 지표 확인 위치
세 모델 비교 후 `summary.json`에서 아래 항목을 확인할 수 있다.

- `A_det`
- `T_inf_rule_ms`
- `T_inf_temporal_ms`
- `T_inf_hybrid_ms`
- `N_param_rule`
- `N_param_temporal`
- `N_param_hybrid`

실제 문맥 일치 확률은 사용자가 영상과 비교해 직접 산정한다.

\[
P_{ctx} = \frac{N_{match}}{N_{total}}
\]

- `N_match`: 실제 상황과 일치한다고 판정한 프레임 수
- `N_total`: 전체 평가 프레임 수
