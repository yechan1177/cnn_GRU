# 30. 프로젝트 종합 인수인계

## 이 문서의 목적
이 문서는 현재 저장소의 최종 상태를 한 번에 전달하기 위한 종합 인수인계 문서다. 새로운 스레드나 새로운 협업자가 GitHub 저장소만 보고도 현재 모델 정의, 논문 재현 경로, 핵심 코드 위치, 주요 산출물, 해석 시 주의사항까지 바로 이어받을 수 있도록 정리한다.

## 저장소의 현재 목적
본 저장소는 실시간 주행 영상을 입력으로 받아 객체를 검출하고, 이를 저차원 의미 기반 특징 벡터와 CNN-GRU 기반 시계열 모델로 해석하여 장면의 상황 맥락을 분류하는 온디바이스 지향 경량 파이프라인을 구현한다. 최종 목표는 향후 VLA 학습에 재사용 가능한 멀티모달 데이터셋 자동 구축의 기반을 만드는 것이다.

현재 논문 및 비교 실험에서 강조하는 핵심은 다음과 같다.
- YOLO 자체가 아니라, YOLO 검출 결과를 의미 기반 특징 벡터로 재구성하는 부분
- 현재 프레임 규칙과 시계열 모델을 결합하는 하이브리드 상황 인지 구조
- 동일한 detector 출력에 대해 세 모델이 어떤 분포 차이를 보이는지 비교하는 체계
- 온디바이스 환경에서도 유지 가능한 계산량 범위 안에서의 구조 검증

## 최종 비교 모델 정의
현재 저장소의 최종 비교 모델은 아래 세 가지로 고정한다.

### 1. YOLO + 순간 규칙
- 입력: 현재 프레임 YOLO 검출 박스
- 특징: feature vector와 시계열 모델을 사용하지 않는다.
- 판단 기준: 현재 프레임에서 사람, 차량, 이륜차가 중앙 시야 ROI에 얼마나 들어왔는지, 얼마나 크게 보이는지, 중심에 얼마나 가까운지를 기반으로 즉시 판단한다.
- 실행 파일: `run_yolo_rule_model.py`

### 2. CNN-GRU only
- 입력: 현재 프레임 기준 16차원 순간 특징 벡터의 최근 8프레임 시퀀스
- 특징: 시간 변화량은 현재 프레임 feature에서 직접 계산하지 않고, 시퀀스 전체를 통해 CNN-GRU가 학습한다.
- 실행 파일: `run_baseline_cnn_gru_model.py`
- 체크포인트: `models/checkpoints/temporal_shared_best.pt`

### 3. CNN-GRU + 규칙 보정
- 입력: 2번 모델과 동일한 CNN-GRU 출력
- 보정 신호: 1번 모델의 현재 프레임 규칙 결과
- 특징: temporal 확률과 현재 프레임 규칙을 함께 사용해 최종 상황 태그를 보정한다.
- 실행 파일: `run_final_model.py`
- 체크포인트: `models/checkpoints/temporal_final_best.pt`
- 룰 파라미터: `configs/hybrid_rule_params.json`

## 현재 feature 정의
현재 temporal 입력 feature는 모두 현재 프레임에서만 계산한다. 직전 프레임 차이 기반 파생값은 제거했고, 시간 변화는 sequence 전체를 통해 학습한다.

- `det_norm`
- `mean_conf`
- `max_conf`
- `mean_area`
- `area_var`
- `vehicle_ratio`
- `person_ratio`
- `bike_ratio`
- `vehicle_conf`
- `person_conf`
- `bike_conf`
- `roi_risk`
- `center_closeness`
- `roi_mean_area`
- `roi_count_norm`
- `roi_vertical_bias`

관련 구현은 `src/vcp/components/spatial.py`를 기준으로 본다.

## 논문 기준 입력 데이터와 학습 단위
- 객체 검출 학습 데이터: Roboflow 기반 자율주행/차량 인식 데이터셋 재구성
- 객체 클래스: `person`, `vehicle`, `bike`
- YOLO 학습 이미지 수: 약 34,880장
- 시계열 입력 단위: 최근 8프레임
- 시계열 feature 차원: 16차원
- 시계열 상황 라벨: `normal_drive`, `front_vehicle_follow`, `brake_warning`, `hard_brake_risk`, `post_brake_recovery`
- 공통 학습 데이터셋: `data/processed/dataset_rule_context_instant_feat16_v2_20260327_162111`

## 현재 논문용 핵심 수치
현재 `people_braking` 기준 비교 실험에서 정리한 핵심 수치는 아래와 같다.

- detector 공통 정확도 `A_det = 0.73491`
- YOLO+rule 엔드투엔드 시간 `T_inf = 8.8745 ms/frame`
- CNN-GRU only 엔드투엔드 시간 `T_inf = 9.8805 ms/frame`
- CNN-GRU+rule 엔드투엔드 시간 `T_inf = 9.8266 ms/frame`

- CNN-GRU only 파라미터 `N_param = 3,227,489`
- CNN-GRU+rule 파라미터 `N_param = 3,227,489`

## 실제 문맥 일치 확률 계산식
실제 이벤트 여부는 사용자가 영상을 직접 보고 판정해야 하므로, 저장소에서는 아래 수식만 제공한다.

\[
P_{ctx} = \frac{N_{match}}{N_{total}}
\]

- `N_match`: 사용자가 실제 상황과 일치한다고 판정한 프레임 수
- `N_total`: 평가 대상 전체 프레임 수

## 결과 해석 시 주의사항
### 1. 제안 모델의 독창성 위치
독창성은 YOLO backbone 자체가 아니라 아래 조합에 있다.
- YOLO 검출 결과를 의미 기반 feature로 재구성한 점
- 현재 프레임 규칙형 baseline과 CNN-GRU를 분리해 비교한 점
- 시계열 출력과 규칙 기반 판단을 hybrid로 결합한 점
- 동일 영상 기준 3모델 비교 및 재현 체계를 구축한 점

### 2. 시간 지표 해석
현재 논문 표에 쓰는 `T_inf`는 end-to-end 기준 프레임당 평균 처리 시간이다. 초기에는 후단 의사결정 시간만 측정한 적이 있었으나, 현재 브랜치 기준 수치는 detector와 후단 처리를 포함하는 end-to-end 측정값으로 정리되었다.

### 3. 브레이크 실험의 의미
브레이크 관련 실험은 특정 브레이크 전용 인식기의 완성도를 주장하기 위한 것이 아니라, 제안한 경량 상황 인지 구조가 실제 주행 영상 변화에 대해 동작 가능한지를 확인하는 검증 사례로 해석한다.

## 새 스레드에서 이어받을 때 바로 설명해야 하는 내용
새로운 대화나 협업에서는 아래 문장을 기준으로 시작하면 가장 정확하다.

- 이 저장소의 핵심은 `YOLO 자체`가 아니라 `YOLO 출력 -> 16차원 의미 특징 -> CNN-GRU -> 규칙 보정`의 하이브리드 파이프라인이다.
- 현재 최종 비교 모델은 `YOLO + 순간 규칙`, `CNN-GRU only`, `CNN-GRU + 규칙 보정`의 세 가지다.
- 논문 재현의 기준 영상은 `people_braking.mp4`이며, 세 모델 비교와 그래프 생성은 `run_compare_three_models.py`와 `scripts/` 아래 재생성 스크립트로 수행한다.
- 논문용 정량 지표는 `A_det`, `T_inf`, `N_param`을 기준으로 하고, 실제 문맥 일치 확률은 사용자가 영상을 보며 계산한다.
