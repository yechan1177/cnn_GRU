# 32. 확증 실험 사전 등록(심사 1차 대응)

- 등록 시점: 2026-10-02, 확증 실험 실행 **전**
- 배경
  - 1차 심사(`paper/review/review_round1_ko.md`) M1·M2에 따르면, 주 결과(2%에서 CARE > 무작위)의 신뢰구간이 시드 변동을 반영하지 않았다.
  - 시드 3개로는 검정력이 부족하다.
  - M5: 1~2% 예산은 파일럿을 본 뒤 추가되어 탐색적 성격이다.
  - M6: 점수기의 기여가 '혼합' 효과와 분리되지 않았다.

## 1. 설계(고정)

| 항목 | 값 |
|---|---|
| 학습 시드 | 3, 4, 5, 6, 7, 8, 9(기존 0~2와 겹치지 않는 7개) |
| 평가 시나리오 | 새 확증 세트: 주행 7 시나리오 × 3 스타일 × 7 = 147 에피소드. 시드 700000번대이며 기존 풀·검증·테스트와 겹치지 않는다 |
| 정책·학습 | 본 실험과 같다(VLA-lite, T=6000, 배치 128, 언어 입력 있음) |
| CARE 설정 | λ=0.5, ρ=0.9(본 실험과 같으며 다시 튜닝하지 않음) |
| 성공 정의 | 무충돌 ∧ 이동 거리 ≥ 0.8×같은 시나리오 전문가 |

## 2. 가설

- **H1(1차)**: 예산 2%에서 CARE의 확증 세트 성공률이 무작위보다 높다(단측).
- **H2(2차)**: 예산 1%에서 CARE > 무작위.
- **H3(2차, 점수기 기여)**: 예산 2%에서 CARE > 같은 저장소(ρ=0.9)에 점수 몫만 다른 점수로 고른 혼합.
  - H3a 감속 트리거 점수 혼합(`mix_trigger`)
  - H3b 오라클 점수 혼합(`mix_oracle`)
  - H3c 불확실성 단독 혼합(`mix_uncert`: λ만 사용, 위험 확률 없음)
- **탐색(검정하지 않음)**: ρ=0.95(λ=0.5) 2%. 경계 최적 여부 확인용으로, 기술 통계만 보고한다.

## 3. 분석 계획

- **주 분석**: 시드·에피소드 2단계 계층 부트스트랩(10,000회)으로 성공률 차이의 95% CI와 단측 p를 구한다.
  - 1단계: 시드를 복원 추출한다.
  - 2단계: 에피소드를 복원 추출한다.
  - 두 방법의 같은 시드 번호를 대응시킨다(같은 시드에서 정책 초기화·미니배치 난수가 같다).
- **H1**: 단측 α=0.05.
- **H2, H3a~c**: Holm 보정으로 가족별 오류율 0.05를 지킨다.
- **보조 분석**: 시드 수준 대응 t 검정(df=6)을 함께 보고한다.
- 결과가 H1을 지지하지 않으면, 원고의 CARE 우위 주장을 '탐색적 관찰'로 낮추고 주 결론을 위험 편향 붕괴로 둔다.
