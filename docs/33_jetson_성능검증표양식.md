# 33. Jetson 성능 검증 표 양식

## 1. 측정 목적
본 문서는 Jetson Orin Nano 배포 후 모델이 실제 환경에서 정상적으로 동작하는지 확인하기 위한 성능 검증 표 양식을 제공한다. 검증의 핵심은 단순한 실행 성공 여부가 아니라, 프레임당 처리 시간, 자원 사용량, 전력 소모, 온도, 객체 검출 성능, 그리고 실제 상황 맥락 일치 정도를 함께 확인하는 데 있다.

## 2. 측정 항목 정의
- `FPS`: 초당 처리 프레임 수를 의미한다.
- `end-to-end latency`: 입력 프레임 1장이 들어온 시점부터 최종 결과가 출력될 때까지 걸리는 전체 시간을 의미한다.
- `CPU usage`: Jetson의 CPU 사용률을 의미한다.
- `GPU usage`: Jetson의 GPU 사용률을 의미한다.
- `RAM usage`: 메모리 사용량을 의미한다.
- `Power`: 소비 전력 또는 전력 모드에 따른 평균 전력 사용량을 의미한다.
- `Temperature`: 동작 중 장치 온도를 의미한다.
- `A_det`: 객체 인식 정확도 지표이며, 본 저장소에서는 detector의 `mAP50`을 기준으로 기록한다.
- `P_ctx`: 실제 문맥 일치 확률을 의미한다.

### 참고 수식
\[
FPS = \frac{1000}{T_{inf}}
\]

\[
P_{ctx} = \frac{N_{match}}{N_{total}}
\]

- `T_inf`: 프레임당 평균 추론 시간(ms/frame)
- `N_match`: 실제 상황과 일치한다고 판정한 프레임 수
- `N_total`: 평가 대상 전체 프레임 수

## 5. 권장 측정 절차
1. Jetson 부팅 후 `nvpmodel`과 `jetson_clocks` 설정을 고정한다.
2. 동일한 입력 영상 또는 동일한 웹캠 조건을 사용한다.
3. 각 모델을 같은 조건에서 한 번씩 실행한다.
4. `tegrastats`로 CPU, GPU, RAM, 전력, 온도를 함께 기록한다.
5. `summary.json` 또는 실행 로그에서 프레임당 추론 시간과 이벤트 수를 읽는다.
6. 실제 상황과 일치하는 프레임 수를 사람이 직접 확인하여 `P_ctx`를 계산한다.
7. 세 모델의 결과를 같은 표 형식으로 정리한다.

## 6. 결과 해석 시 주의사항
- `FPS`와 `T_inf`는 같은 의미가 아니므로 둘을 구분해서 기록한다.
- `A_det`가 같더라도 후단 시계열 모델의 맥락 분포는 달라질 수 있다.
- `P_ctx`는 자동 정답이 아니라 사람 기준 판정값이므로, 판정 기준을 실험마다 바꾸지 않아야 한다.
- Jetson의 전력 모드와 성능 모드는 결과에 큰 영향을 주므로 반드시 함께 적는다.
- mp4와 webcam은 입력 특성이 다르므로 서로 다른 실험으로 기록하는 것이 좋다.
- 동일 영상이라도 해상도, batch size, 저장 정책이 달라지면 결과가 달라질 수 있다.

## 7. 사용 방식
이 문서는 Jetson 배포 후 성능 측정값을 손으로 기록하거나, 실행 로그와 함께 비교표를 만들 때 기준 양식으로 사용한다.
