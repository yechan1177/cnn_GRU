# 34. v3 사전 등록(exp_120_vla_v3)

- 작성: 2026-10-04
- 커밋 시점: v3 테스트·반사실·AMR 테스트·실영상 실행 **전**. 이 문서를 커밋한 뒤 결과를 보고 아래 항목을 바꾸지 않는다. 바꿔야 하면 바뀐 내용과 이유를 별도 절("등록 후 변경")에 남기고, 원고에서 탐색적 분석으로 표시한다.
- 근거: docs/33(KPI·개선 계획), 28a "v3 추가 계약"

## 1. 고정 설정
| 항목 | 값 |
|---|---|
| 정책 | VLA-lite + 검출 특징 토큰(v1v2 32차원 × 프레임 t, t−2), 언어 FiLM, 속도 입력 |
| 학습 | 경사 단계 T = 6000, 배치 128. 모든 조건에서 동일. 파일럿은 학습 단계 수 확인용이며, 전체 데이터 검증 성공률이 T=3000에서 더 높아도 T는 바꾸지 않고 그 사실을 보고한다 |
| 벤치마크 | decouple_initial_speed=True, collision_pushback=False |
| 점수기 | v2와 같은 점수기(같은 초기 라벨 셋·시드), 재학습하지 않음 |
| 클립 길이 | L = 30프레임, 예산 K = round(βN/L) |
| 성공 정의 | 무충돌 ∧ 이동 거리 ≥ 0.8 × 전문가 거리(전문가 거리 < 1 m이면 진행 조건 면제). AMR은 주행 중 충돌만 실패로 셈 |
| λ, ρ 선택 규칙 | 격자 λ∈{0, 0.5} × ρ∈{0.8, 0.9, 0.95}, 2%, 검증 세트 성공률(주행: 시드 0·1 평균, AMR: 시드 0) 최대. 동률이면 격자 순서상 앞의 값 |

## 2. 평가 세트(시드 분리)
| 세트 | 주행 시드 기준 | AMR 시드 기준 | 크기 |
|---|---|---|---|
| 풀 | 100000 | 400000 | 1200 / 600 에피소드 |
| 검증 | 150000 | 450000 | 셀당 2 |
| 테스트 | 800000 | 900000 | 셀당 7 / 4 |
| 반사실 | 850000 | — | 셀당 3 × 스타일 3 |
| 개루프 테스트 풀 | 300000 | 600000 | 150 / 90 에피소드 |

테스트 시드는 v2의 테스트(200000번대)·확증(700000번대) 세트와 겹치지 않는다.

## 3. 가설과 판정
| ID | 가설 | 분석 | 판정 규칙 |
|---|---|---|---|
| K1 | CARE 2% 테스트 성공률 ≥ 0.80 | 시드 10개 평균 | 점추정이 목표 이상이면 달성 |
| K2 | CARE 2% / 전체 100% ≥ 0.90 | 시드 평균 비율 | 점추정 기준 |
| K3 | CARE 2% 위험 시나리오 성공률 ≥ 0.75 | 위험 시나리오 에피소드만 | 점추정 기준 |
| K4 (주 확증 가설) | CARE − 저장소+감속 트리거(공유 저장소, 2%) > 0 | 시드·에피소드 계층 부트스트랩(10,000회), 같은 시드 번호 대응 | Holm 보정 단측 p < 0.05이고 95% CI 하한 > 0 |
| H-a | CARE − 무작위(공유 저장소, 2%) > 0 | 같음 | 같음(Holm 군에 포함) |
| H-b | CARE − 저장소+오라클(2%) | 같음 | 같음(Holm 군에 포함, 방향 예측 없음 → 결과 그대로 보고) |
| K5 | AMR CARE − 무작위(공유 저장소, 2%) ≥ −0.03(비열등) | 계층 부트스트랩, 시드 5개 | 95% CI 하한 > −0.03 |
| K6 | 반사실 평가에서 언어 입력이 속도 추종 오차를 30% 이상 줄임(CARE 2%) | 시드 5개 평균 오차 비교, 언어 있음/없음 같은 시드 | 감소율 ≥ 0.30. 전체 데이터 결과는 보조 보고 |
| K7 | 실영상 전체 데이터 정책(특징 토큰) 제동 시작 AUROC ≥ 0.65 | 블록 5-fold × 시드 2 평균 | 점추정 기준. 특징 토큰 없는 정책과 비교 보고 |

- 보조(탐색적) 분석: 1%·5% 예산 CARE − 무작위, 감속 트리거 단독(위험 편향 붕괴 재현), 저장소+트리거 − 무작위, 스타일별 추종 간격 분리도, 실영상 10·20% 방법 간 비교.
- 목표 미달 지표도 그대로 보고한다. 실험 일부가 컨테이너 재시작으로 중단되면 같은 설정으로 재개하고, 완료하지 못한 조건은 "미측정"으로 보고한다.

## 4. 등록 후 변경
아래 변경은 모두 해당 결과가 나오기 전에 했고, 판정 규칙(3절)은 바꾸지 않았다.

1. **실영상 학습 단계 수 명확화(2026-10-04 13:25 UTC, 실영상 실행 전).** 1절의 "T = 6000, 모든 조건에서 동일"은 시뮬레이터(주행·AMR) 실험에 대한 문구다. 실영상(K7)은 v2 실영상 실험과 같은 T = 1500을 쓴다. 이 값은 사전 등록과 같은 커밋(`bee8b95`)의 `comma_v3.py` 기본값으로 이미 고정되어 있었다. 실영상 안에서는 모든 조건이 같은 T를 쓴다.
2. **반사실 세트 성공 판정의 키 수정(2026-10-04 13:25 UTC, 언어 단계 실행 전).** 반사실 세트는 같은 (시나리오, 시드)를 세 스타일로 평가한다. 그래서 전문가 기준 거리를 (시나리오, 시드)로 찾으면 마지막 스타일의 거리만 남는다. 이를 (시나리오, 시드, 스타일)로 찾도록 고쳤다(`vla_v3_report.episode_success`). 검증·테스트 세트는 (시나리오, 시드)가 모두 고유하다(42/42, 147/147). 따라서 이 두 세트의 판정은 바뀌지 않는다. K6(속도 추종 오차)은 성공 판정을 쓰지 않으므로 영향이 없다.
