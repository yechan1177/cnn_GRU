## 3. 가설과 판정(새 테스트 세트)
K1~K7의 정의와 판정 규칙은 v3(docs/34 3절)와 같다. 단, 모두 v4 설정에서 계산한다.

| ID | 가설 | 분석 | 판정 |
|---|---|---|---|
| K1 | v4 CARE 2% 성공률 ≥ 0.80 | 시드 10개 평균 | 점추정 |
| K2 | v4 CARE 2% / v4 전체 100% ≥ 0.90 | 시드 평균 비율(전체는 시드 5개) | 점추정 |
| K3 | v4 CARE 2% 위험 시나리오 성공률 ≥ 0.75 | 위험 시나리오 에피소드 | 점추정 |
| K4 | v4 CARE − v4 저장소+감속 트리거 > 0 | 계층 부트스트랩(10,000회), 같은 시드 대응 | Holm 보정 단측 p < 0.05이고 95% CI 하한 > 0 |
| H-a | v4 CARE − v4 무작위(공유 저장소) > 0 | 같음 | Holm 군 포함 |
| H-v | v4 CARE − v3 CARE > 0(개선 효과, 같은 새 테스트) | 같음 | Holm 군 포함 |
| K5 | AMR v4 CARE − v4 무작위 ≥ −0.03(비열등) | 계층 부트스트랩, 시드 5개 | 95% CI 하한 > −0.03 |
| K6 | 반사실 평가에서 언어가 속도 추종 오차를 30% 이상 줄임(v4 CARE 2%) | 시드 5개 평균, 언어 있음/없음 같은 시드 | 감소율 ≥ 0.30. 전체 데이터는 보조 |
| K7 | 실영상 v4 전체 데이터 정책 제동 시작 AUROC ≥ 0.65 | 블록 5-fold × 시드 2 평균 | 점추정. 정책 없는 −a_t 기준선과 v3 실영상 결과(0.528)를 함께 보고 |

- Holm 보정 군: K4, H-a, H-v.
- 보조(탐색적): v4 무작위 − v3 무작위, v3 CARE − v3 무작위(새 테스트에서 v3 효과 재현), 스타일별 속도·간격, 실영상 10·20% 방법 간 비교.

- 목표 미달 지표도 그대로 보고한다. 컨테이너 재시작으로 중단되면 같은 설정으로 재개하고, 끝내지 못한 조건은 "미측정"으로 보고한다.
