## 2. 탐색적 절제(2026-10-05 05:11~07:45, 55작업 + 제어기 단독 1회)
### 2.1 K6 분해(반사실 새 테스트, CARE 2%, `v4_explore_k6`)
| 조건 | 속도 오차(m/s) |
|---|---|

| v4, 언어 없음(P6·P7도 꺼짐) | 2.60 |
| 전부+P6(P7 없음), 언어 있음 / 없음 | 2.74 / 2.60 |
| P6·P7만(학습 언어 임베딩·FiLM 없음) | **1.15** |
| 제어기 단독(학습 없음) | 2.13 |

해석
- K6를 달성하게 한 효과는 지시문 숫자를 결정적으로 읽어 비례 제어 기준을 만드는 P6·P7 경로에서 나온다.
- 학습 언어 경로는 수치 목표만 쓸 때보다 오차를 오히려 늘린다(1.15 → 1.62).
- P7 없이 P6만 쓰면 언어 효과가 없다.
- 학습 정책 + 잔차(1.15)는 제어기 단독(2.13)보다 낫다. 잔차 학습이 기여하는 몫은 있다.
- 따라서 "정책이 언어를 학습해 지시를 따른다"는 주장은 지지되지 않는다. K6의 사전 등록 판정은 '달성'으로 두되, 원고에서는 "구조화된 수치 목표 추출 + 잔차 제어로 달성, 학습 언어 접지는 미확인"으로 쓴다.
