## 3. 가설과 판정
### 3.1 재현(KPI 판정, docs/34·37과 같은 규칙)
K1·K2·K3·K5·K6는 점추정과 판정 규칙이 docs/37과 같다. 각각 95% 부트스트랩 CI와 목표 이상 비율을 함께 보고한다. K4는 v4 CARE − v4 트리거 혼합의 95% CI 하한 > 0으로 판정한다. K5는 시드 10개로 판정한다.

### 3.2 확증 가설(Holm 군 A, 단측 α = 0.05)
| ID | 가설 | 분석 |
|---|---|---|
| H-v3 | v4 CARE − v3 CARE > 0 | 시드·에피소드 계층 부트스트랩(10,000회) |
| H-a3 | v4 CARE − v4 무작위 > 0 | 같음 |
| H-a3n | v4_noaux CARE − v4_noaux 무작위 > 0(점수기 출력을 학습에 쓰지 않을 때 CARE 선별 효과) | 같음 |
| H-P7 | v4 CARE − 전부+P6 CARE > 0(P7이 폐루프 성공률에 기여) | 같음 |
| H-L | cf3에서 v4(언어 있음) 속도 오차 − P6·P7만 속도 오차 < 0(학습 언어 경로가 수치 목표 경로보다 오차를 더 줄임) | 시드 대응 차이의 시드 부트스트랩 |

판정: Holm 보정 단측 p < 0.05이면 지지, 아니면 미지지.

### 3.3 동등성(H-K4e, TOST)
v4_noaux CARE − v4_noaux 트리거 혼합의 90% 계층 부트스트랩 CI가 (−0.03, +0.03) 안에 있으면 "동등"으로 판정한다. 동등 한계 0.03은 v3 K5 비열등 한계와 같은 값으로, 결과를 보기 전에 정했다.

### 3.4 블록별 제거(A7, Holm 군 B)
각 블록 b에 대해 Δ_b = v4 CARE − (b 제거) CARE를 구하고, 계층 부트스트랩 단측 p(Δ ≤ 0)를 Holm으로 보정한다. 시드가 5개라 검정력이 낮다. 미지지는 "효과 없음"이 아니라 "검출 못 함"으로 보고한다.

### 3.5 보조(탐색적, 판정 없음)
트리거 혼합 − 무작위(v4, v4_noaux), v4 − v4_noaux(CARE), K6 시드별 감소율, 전부+P6의 언어 효과, 제어기 단독 오차, AMR v4 − v3 CARE, 실영상 v4+P5의 AUROC와 −a_t 기준선.

## 4. 해석 규칙(결과 전 확정)
- H-L이 미지지이고 P6·P7만 조건의 오차가 v4 언어 있음 조건 이하이면, 원고는 "K6 달성은 수치 목표 경로(P6·P7) 덕분이며, 학습 언어 접지는 확인되지 않음"으로 쓴다.
- H-a3n이 미지지이면 "CARE 선별의 고유 효과는 점수기 출력을 학습에 쓰지 않는 조건에서 확인되지 않음"으로 쓴다.
- H-K4e가 동등이면 "±0.03 안에서 CARE와 트리거 혼합이 동등"으로, 동등이 아니면 "차이도 동등도 확정하지 못함"으로 쓴다.
- 세 번째 테스트 세트 결과가 두 번째와 다르면 두 결과를 모두 보고하고 고르지 않는다.
