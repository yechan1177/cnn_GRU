## 4. 실험 설계

본 실험의 질문은 하나이다. **같은 저장 예산에서 어떤 선별법이 고른 데이터가 VLA 정책의 폐루프 성공률을 가장 높이는가?**

이 질문에 공정하게 답하려면 선별법 이외의 요인이 결과를 바꾸지 않아야 한다. 이를 위해 본 실험에 앞서 변수를 정의하고(4.1), 결과에 영향을 줄 수 있는 변수를 측정하여 값을 결정한 뒤(4.2), 나머지 변수를 통제했다(4.3). 4.4절은 실험 환경을, 4.5절은 세부 설정을 기술한다.

### 4.1 변수 정의

| 구분 | 변수 | 수준·정의 |
|---|---|---|
| 독립 변수 | 선별법 | 무작위, 등간격, 감속 트리거, 역 TTC 규칙, 불확실성, Coreset, 맥락 이벤트, CARE, 오프라인 손실*, 오라클*(* 수집 시점 계산 불가) |
| 독립 변수 | 저장 예산 β | 1%, 2%, 5%, 10% (+ 참고: 100%). 주 예산 2%에서는 10개 방법 전부, 나머지 예산에서는 핵심 6개 방법(무작위, 감속 트리거, 불확실성, 맥락 이벤트, 오라클, CARE) |
| 종속 변수(주) | 폐루프 성공률 | 무충돌 ∧ 이동 거리 ≥ 0.8×전문가 |
| 종속 변수(보조) | 위험 시나리오 성공률, 충돌률, 속도 오차, 추종 간격, RMS jerk, 개루프 행동 MAE(전체·위험 구간) | 3.6절 정의 |
| 매개 변수(진단) | 선택 데이터의 위험 프레임 회수율, 라벨 분포 엔트로피, 에피소드 커버리지 | 선별 결과의 구성 |
| 통제 변수 | 정책 구조, 경사 단계 수 $T$, 배치, 학습률·스케줄, 증강, 클립 길이 $L$, 평가 시나리오·시드, 검출 잡음 수준, 점수기 | 4.3절 |

### 4.2 변수 측정(파일럿)

본 실험에 앞서 **검증 시나리오만** 사용하여 아래 값을 측정하고 결정했다. 검증 시나리오는 테스트와 시드가 겹치지 않는다(시나리오 7종 × 스타일 3종 × 2 = 42 에피소드). 테스트 결과를 보고 설정을 변경하지 않았다.

**(1) 풀 분포와 희소도.** 큐레이션 풀은 주행 {{s:pool_episodes:0}} 에피소드, {{s:pool_frames:0}} 프레임으로 구성된다.

- GT 위험 프레임(제동 경고 + 강한 제동 위험)은 전체의 {{p:pool_hazard_ratio}}이다.
- 위험 구간은 {{s:pool_hazard_events:0}}개이다.
- 무작위 10% 선택에 포함되는 위험 프레임은 기댓값 기준 약 {{s:pool_hazard_frames_10pct:0}}개에 불과하다. 이는 희소 위험의 과소표집 문제를 정량적으로 보여준다.
- 클래스별 비율은 표 2에 제시했다.

{{table:pool_distribution}}

표 2. 큐레이션 풀(주행)의 맥락 분포.

**(2) 점수기 품질.** 부트스트랩 라벨 셋(기존 합성 데이터 700 에피소드, 풀과 시드 분리)으로 학습한 점수기의 검증 성능은 다음과 같다.

- macro-F1 {{s:scorer_val_macro_f1}}, 위험 판별 AUROC {{s:scorer_val_hazard_auroc}}
- 같은 점수기를 새 풀에 적용한 위험 프레임 AUROC는 {{s:pool_scorer_auroc}}이다. 풀은 지시문 스타일이 추가되어 분포가 다르다.

**(3) 경사 단계 수.** 전체 데이터와 무작위 10% 데이터로 $T\in\{1000, 3000, 6000\}$을 비교했다(표 3).

- 전체 데이터의 검증 성공률은 $T$=1000, 3000, 6000에서 각각 {{s:pilot:full:1.00:1000:success}}, {{s:pilot:full:1.00:3000:success}}, {{s:pilot:full:1.00:6000:success}}였다.
- 무작위 10%는 각각 {{s:pilot:random:0.10:1000:success}}, {{s:pilot:random:0.10:3000:success}}, {{s:pilot:random:0.10:6000:success}}였다.

전체 데이터는 3000단계에서 아직 수렴하지 않았다. $T$를 작게 잡으면 데이터가 많은 조건만 불리해지는 교란이 생기므로 $T$=6000으로 정했다.

표 3. 파일럿(검증 시나리오, 시드 0 기준이며 시드 수 열이 2 이상이면 평균 ± 표준편차). 경사 단계 수, 시드 반복, 예산 규모에 따른 결과.

**(4) 예산 규모.** 처음 설계한 예산 범위(5~20%)의 하단인 5%와 10%에서도 무작위 선택의 검증 성공률이 이미 {{s:pilot:random:0.10:6000:success}}(10%)과 {{s:pilot:random:0.05:6000:success}}(5%)에 이르러, 방법 간 차이가 천장 효과에 가려질 우려가 있었다. 따라서 예산을 1%와 2%까지 낮추어 측정했다.

- **무작위**
  - 1%: 성공률 {{s:pilot:random:0.01:6000:success}}, 충돌률 {{s:pilot_coll:random:0.01}}
  - 2%: 성공률 {{s:pilot:random:0.02:6000:success}}, 충돌률 {{s:pilot_coll:random:0.02}}
  - 위험 상황에서의 실패가 뚜렷했다.
- **위험 구간만 고르는 방법**: 감속 트리거와 오라클의 2% 성공률은 각각 {{s:pilot:action_trigger:0.02:6000:success}}, {{s:pilot:oracle:0.02:6000:success}}였다. 충돌은 거의 없었으나 정책이 서행만 학습하여 진행 기준을 넘지 못했다(5.3절).

이를 근거로 예산을 {1, 2, 5, 10}%로 설정하고, 위험 실패와 과잉 서행이 모두 드러나는 2%를 주 예산으로 정했다.

**(5) 시드 분산과 검출 가능 효과.** 1차 파일럿($T$=3000)에서 시드 3개를 반복했을 때 성공률의 시드 표준편차는 다음과 같았다.

- 전체 데이터: {{s:pilot_sd_full}}
- 무작위 10%: {{s:pilot_sd_random}}
- 오라클 10%: {{s:pilot_sd_oracle}}

테스트 에피소드 {{s:driving_n_test:0}}개에서 대응 비교의 성공률 차이 표준오차는 약 {{s:pilot_se_diff}}로 추정된다. 따라서 시드 3개 평균에서 약 {{p:pilot_mde}}p 이상의 차이를 검출할 수 있다고 판단하여 시드를 3개로 정했다.

**(6) CARE 하이퍼파라미터.** 처음 설정한 $\rho$=0.3은 2차 파일럿에서 정상 주행 성능을 무너뜨렸다(2% 성공률 {{s:pilot:ours:0.02:6000:success}}, 속도 오차 {{s:pilot_spd:ours:0.02:2}} m/s). 이에 주 예산 2%, 시드 0에서 $\lambda\in\{0,0.5\}$와 $\rho\in\{0.25,0.5,0.75,0.9\}$의 8개 조합을 검증 성공률로 비교했으며, 동률일 때는 속도 오차로 우열을 가렸다(표 4).

### 4.3 통제

- **학습 계산량**
  - 모든 조건에서 정책 구조, $T$, 배치(128), AdamW(학습률 $10^{-3}$, cosine), 증강(±2px 평행이동, 밝기·대비 지터)을 고정했다.
  - 따라서 데이터가 적은 조건은 같은 표본을 더 여러 번 보게 된다. 본 실험이 비교하는 것은 '같은 계산 예산에서 어떤 데이터가 더 유익한가'이다.
- **선택량**: 모든 방법이 정확히 $K_\beta$개 클립($L$=30프레임=2초)을 선택하므로 학습 프레임 수가 같다.
- **학습 데이터 경계**: 과거 프레임($t-2$)과 행동 청크 타깃은 클립 내부에서만 구성한다. 전체 데이터(100%) 조건에도 같은 클립 분할을 적용하여 경계 효과를 동일하게 맞췄다.
- **평가**
  - 모든 조건은 같은 테스트 시나리오 {{s:driving_n_test:0}}개(시나리오 7종 × 스타일 3종 × 7)를 사용한다. 시드는 200000번대로, 학습 풀(100000번대)·검증(150000번대)과 겹치지 않는다.
  - 차이의 신뢰구간은 에피소드 대응 부트스트랩(4000회)으로 구한다.
- **점수기 분리**: 점수기는 큐레이션 풀과 시드가 다른 기존 데이터로 학습했으며, 정책 학습이나 테스트 정보를 참조하지 않는다.
- **난수**
  - 선택 난수(무작위·저장소·동률 처리)는 시드별로 고정했다.
  - 정책 초기화와 미니배치 난수도 시드로 고정했다.
  - 따라서 같은 시드에서 방법 간 차이는 선택된 데이터에서만 발생한다.
- **검출 잡음**: 점수기 입력에는 동일한 잡음 모델을 적용했다(누락 5%, 오검출 15%, 박스 흔들림 4%, 보행자·이륜차 혼동 5%).

| 시드 | 3 | 3 |
| 성공 기준 | 무충돌 ∧ 진행 ≥ 0.8×전문가 | 주행 중 무충돌(자차 >0.1 m/s) ∧ 진행 ≥ 0.8×전문가 |

AMR에서는 정지한 로봇에 작업자가 다가와 부딪히는 경우가 전문가 제어에서도 발생한다(전문가 충돌률 {{p:robot_expert_collision}}). 따라서 자차가 움직이는 동안의 충돌만 실패로 집계한다.

실주행(comma) 실험의 설정은 다음과 같다.

- 10fps 프레임 10,200장, 5개 시간 블록, 블록 경계 ±10프레임 제외
- 클립 20프레임(2초), 예산 10 / 20%, 정책 $T$=1500, 행동 청크 10스텝(1초)
- 시드 2개 × fold 5개
