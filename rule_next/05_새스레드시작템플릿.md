# 새 스레드 시작 템플릿

아래 템플릿은 새로운 프로젝트나 새로운 대화 스레드에서 바로 붙여 넣어 사용할 수 있는 기본 규칙 묶음이다.

```md
## 작업 기본 규칙
- 작업 시작 전에 목표와 범위를 짧게 정리한다.
- 태스크 문서를 만들고 체크리스트로 진행 상태를 관리한다.
- 코드 변경 시 README, docs, tasks 중 관련 문서를 함께 갱신한다.
- 검증하지 않은 성능 수치나 결과는 단정하지 않는다.
- 실험 결과와 산출물은 다시 찾기 쉽게 `experiments/`, `artifacts/`, `docs/`, `tasks/`에 나눠 저장한다.
- 타입 힌트, config 기반 설계, 예외 처리, 재현 가능한 실행 경로를 유지한다.
- 완료하지 않은 작업은 완료로 표시하지 않는다.

## 기본 작업 순서
1. 목표 정의
2. 태스크 문서 작성
3. 구현
4. 문서 반영
5. 검증
6. 결과 요약 및 남은 이슈 기록

## 결과 보고 형식
- 무엇을 바꿨는지
- 어떤 파일이 바뀌었는지
- 어떻게 검증했는지
- 아직 남은 위험이 있는지
```

## 추천 사용 방법
- 새로운 저장소에서는 이 템플릿을 `AGENTS.md`나 `PROJECT_RULES.md`의 시작점으로 사용한다.
- 특정 프로젝트에 맞는 세부 규칙은 이 템플릿 아래에 별도로 추가한다.
- 연구 내용, 도메인 지식, 실험 수치는 이 문서에 넣지 않는다.
