# rule_next

`rule_next/`는 특정 연구 내용과 무관하게, 새로운 프로젝트나 새로운 대화 스레드에서도 그대로 재사용할 수 있는 **기본 운영 규칙 세트**를 모아둔 폴더다.

이 폴더에는 아래 내용만 포함한다.
- 작업 시작과 종료 방식
- 문서화 규칙
- 태스크 기록 규칙
- 코드 작성 규칙
- 산출물 정리 규칙
- 새 스레드 시작용 템플릿

즉, 실제 모델 구조나 실험 결과 같은 프로젝트 고유 정보는 넣지 않고, 어떤 프로젝트에도 공통으로 적용할 수 있는 운영 원칙만 정리한다.

## 사용 순서
1. `01_운영원칙.md`를 먼저 읽는다.
2. `02_태스크기록규칙.md`와 `03_문서코드규칙.md`를 기준으로 작업한다.
3. `04_산출물정리규칙.md`를 따라 결과물을 정리한다.
4. 새 스레드나 새 프로젝트를 시작할 때는 `05_새스레드시작템플릿.md`를 복사해 기본 지침으로 사용한다.

## 포함 문서
- `01_운영원칙.md`
- `02_태스크기록규칙.md`
- `03_문서코드규칙.md`
- `04_산출물정리규칙.md`
- `05_새스레드시작템플릿.md`
